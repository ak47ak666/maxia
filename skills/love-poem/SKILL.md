# 诗歌创作规则

## 技能描述
提供中国古典诗歌的创作规则和指导，帮助用户学习和创作古诗。

## 功能模块

### 1. 古体诗规则

#### 五言古诗
- 每句五个字
- 句数不限
- 不讲究平仄
- 押韵自由
- 适合表达叙事和抒情

#### 七言古诗
- 每句七个字
- 句数不限
- 不讲究平仄
- 押韵自由
- 气势较为宏大

### 2. 近体诗规则

#### 绝句
- 五言绝句：四句，每句五字，共二十字
- 七言绝句：四句，每句七字，共二十八字
- 讲究平仄
- 押韵严格
- 结构紧凑

#### 律诗
- 五言律诗：八句，每句五字，共四十字
- 七言律诗：八句，每句七字，共五十六字
- 讲究平仄
- 押韵严格
- 中间两联需要对仗

### 3. 平仄格律

#### 平声
- 阴平（一声）：妈、花、天、飞
- 阳平（二声）：麻、华、田、肥

#### 仄声
- 上声（三声）：马、假、甜、匪
- 去声（四声）：骂、化、电、费
- 入声：短促急收的声调

#### 平仄规律
- 一三五不论，二四六分明
- 句内平仄相间
- 联间平仄相对

### 4. 押韵规则

#### 韵脚位置
- 绝句：第一、二、四句押韵（首句可不入韵）
- 律诗：第一、二、四、六、八句押韵（首句可不入韵）

#### 韵部
- 平水韵：传统韵书，共106韵部
- 中华新韵：现代韵书，按普通话划分

#### 押韵要求
- 同韵部字可押
- 避免重复用韵
- 避免出韵

### 5. 对仗要求

#### 律诗对仗
- 颔联（第三、四句）必须对仗
- 颈联（第五、六句）必须对仗
- 首尾联不对仗

#### 对仗类型
- 工对：严格对仗，词性、类别完全对应
- 宽对：相对宽松的对仗
- 流水对：上下句意思连贯

#### 对仗要求
- 词性相同
- 结构相同
- 意义相关或相对
- 避免合掌（意思重复）

### 6. 意境营造

#### 常用意象
- 自然意象：山、水、月、风、云、雨、雪、花
- 季节意象：春、夏、秋、冬
- 时间意象：朝、暮、昼、夜
- 情感意象：思、愁、喜、悲

#### 表现手法
- 赋：直接铺陈
- 比：比喻
- 兴：托物起兴
- 虚实结合
- 动静结合

## 使用示例

### 五言绝句示例
```
床前明月光，
疑是地上霜。
举头望明月，
低头思故乡。
```

### 七言绝句示例
```
白日依山尽，
黄河入海流。
欲穷千里目，
更上一层楼。
```

### 五言律诗示例
```
国破山河在，
城春草木深。
感时花溅泪，
恨别鸟惊心。
烽火连三月，
家书抵万金。
白头搔更短，
浑欲不胜簪。
```

## 创作建议

1. **多读多背**：熟读经典诗作，培养语感
2. **由浅入深**：从简单的绝句开始，逐渐尝试律诗
3. **注意格律**：初学者应严格遵守格律规则
4. **注重意境**：诗歌的灵魂在于意境和情感
5. **反复修改**：好诗是改出来的

## 注意事项

- 避免生僻字
- 避免意思重复
- 注意语言的自然流畅
- 传承与创新并重
